# Brand Assets

## Logo Swap Instructions
To replace the default placeholder wordmark:
1. Replace `public/brand/wordmark.svg` with your official Karmatix vector SVG logo (keep viewBox `0 0 280 40` or update width and height in `src/components/Header.astro`).
2. Replace `public/favicon.svg` and `public/apple-touch-icon.png` with your branded iconography.
3. No configuration edits are required as `Header.astro` references `/brand/wordmark.svg` directly.
